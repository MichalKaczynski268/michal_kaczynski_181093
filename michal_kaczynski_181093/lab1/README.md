# VolleyShop — Sklep Siatkarski

Projekt sklepu siatkarskiego na Laboratorium 1.

## Uruchomienie

1. Otwórz terminal w katalogu lab1.
2. Uruchom serwer lokalny poleceniem:
   python -m http.server 8000
3. Wpisz w przeglądarce adres:
   http://localhost:8000/
